# Kitsu Exporter

Kitsu API(Gazu)를 사용하여 프로젝트의 샷 리스트, 상태, 작업자(Task) 배정 정보 및 썸네일 이미지를 엑셀 파일로 추출하는 터미널 전용(TUI) 도구입니다.

## 주요 기능
- **직관적인 TUI (Terminal UI)**: 터미널 환경에서 마우스와 키보드로 조작 가능한 편리한 UI 제공.
- **자동 로그인 (Remember Me)**: 로그인 정보를 안전하게 로컬에 저장하여(`~/.kitsu_exporter_config.json`), 다음번 실행 시 번거로운 입력 없이 자동 접속.
- **강력한 검색 및 필터링**:
  - 샷 이름이나 시퀀스 이름으로 기본 텍스트 검색.
  - 고급 검색 문법 지원 (예: 특정 공정의 작업자 배정 현황 검색 - `assignedto[comp]=홍길동`).
- **고도화된 엑셀 추출**: 
  - 각 샷의 썸네일 이미지를 엑셀 셀 내에 자동으로 크기 맞춤 삽입.
  - 가독성을 높인 셀 서식 (가운데 정렬, 텍스트 줄바꿈, 굵은 테두리 등) 적용 및 단일 페이지 인쇄 최적화.
- **안전한 파일명 자동 생성**: 파일 저장 시 시스템의 `Downloads` (다운로드) 폴더에 현재 날짜와 시간(타임스탬프)을 포함한 파일명으로 자동 저장되어, 연속적인 추출 시에도 파일 덮어쓰기나 충돌을 방지 (`{프로젝트명}_shots_YYYYMMDD_HHMMSS.xlsx`).
- **`uv`를 사용한 간편한 설치 및 독립적 환경 실행** 지원.

## 설치 및 실행 방법

### 1. 전제 조건
- Python 3.12 이상
- [uv](https://github.com/astral-sh/uv) 설치 권장

### 2. 설치 및 실행 방법

프로젝트 디렉토리에서 다음 명령어를 입력하여 환경을 구축하고 앱을 실행합니다:

```bash
# 의존성 설치 및 환경 구축
uv sync

# 💡팁: 다른 PC나 다른 운영체제(OS)에서 설치할 때 uv.lock 파일이 변경되는 것을 방지하려면 아래 명령어 사용을 권장합니다.
uv sync --locked

# 앱 실행 (두 명령어 모두 가능)
uv run kitsu-exporter
# 또는
uv run kitsu_exporter
```

또는 시스템 전역 명령어로 설치하여 어느 디렉토리에서든 직접 실행할 수도 있습니다 (권장):

```bash
uv tool install .
kitsu-exporter # 또는 kitsu_exporter
```

> [!WARNING]
> 설치 후 `command not found: kitsu-exporter` 에러가 발생한다면, 터미널(zsh/bash)에 경로가 추가되지 않은 것입니다. 다음 명령어를 실행하여 경로를 추가하고 터미널을 재시작하세요:
> `uv tool update-shell`

> [!TIP]
> 테스트 목적으로 엔트리 포인트 설치 없이 소스코드 베이스로 바로 실행하려면 다음 명령을 사용하세요:
> `uv run python -m kitsu_exporter.app`

## 사용법
1. **로그인**: 앱 실행 후 Kitsu 서버 주소, 이메일, 비밀번호를 입력합니다.
   - **서버 주소**: `kitsu.yourstudio.com` 처럼 도메인 주소만 입력해도 시스템이 자동으로 올바른 API URL(`https://.../api`) 형태로 보정합니다.
   - **Remember Me**: 체크박스를 켜두면 다음 접속 시 자동으로 진행됩니다.
2. **프로젝트 선택**: 데이터를 추출할 프로젝트를 목록에서 찾아 클릭(또는 Enter)합니다.
3. **데이터 필터링 준비**: 데이터를 Kitsu 서버에서 불러옵니다. (샷 갯수에 따라 잠시 대기). 불러오기가 완료되면 Export 버튼이 활성화됩니다.
4. **검색 (선택 사항)**: 상단 검색창에서 특정 시퀀스나 샷 이름, 또는 `assignedto[]=` 문법을 사용하여 추출할 대상을 미리 좁혀볼 수 있습니다.
5. **엑셀 추출**: `Export` 버튼을 클릭("Enter")하여 추출을 시작합니다. 썸네일을 다운받아 엑셀에 삽입하는 작업이 진행됩니다.
6. **완료**: 앱 하단 상태 메시지에 표시된 대로, 추출된 파일은 사용자의 **다운로드(`Downloads`) 폴더**에 저장됩니다. (예: `기본프로젝트명_shots_20260309_153000.xlsx`)
